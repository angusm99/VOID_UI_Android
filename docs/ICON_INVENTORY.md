```

├── ic_claude_v1.xml → ic_grok_v5.xml          (288 branded core icons)

app/src/main/res/drawable-nodpi/
└── [Same structure, bare icons without padding]

└── appfilter.xml                               (202 launcher mappings for Samsung One UI + AOSP)
```

## Design Philosophy

**VOID UI Core:**
- Pure black backgrounds (AMOLED-friendly, power-efficient)
- Consistent 3–4px white monoline strokes
- 1:1 pixel grid adherence
- Semantic icon matching (form follows function)
- Premium minimalism without unnecessary detail

**Premium Packs:**
- **CIRCUITRY:** Tech aesthetics with glowing endpoints, matrix green accents
- **TERMINAL:** Retro computing, amber CRT phosphor glow, 90° angles
- **XENOCOMM:** Sci-fi futurism, bioluminescent curves, alien otherworldliness
- **CRICKET NATIONS:** Cultural specificity, geometric abstraction, sporting pride
- **SPORTS ZONES:** Runtime adaptability, team identity preservation, dynamic theming

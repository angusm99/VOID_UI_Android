# Privacy Policy for VOID UI Icon Pack

Last updated: May 6, 2026

VOID UI Icon Pack is an Android icon pack for compatible third-party launchers. The app provides launcher icon resources and app-to-icon mappings.

## Data Collection

VOID UI Icon Pack does not collect, store, sell, or share personal user data.

The app does not require an account, does not include advertising, does not use analytics, and does not transmit user data to the developer or to third parties.

## App Permissions

VOID UI Icon Pack does not request sensitive Android permissions. Compatible launchers may read the icon resources and mappings included in the app so they can apply the icon pack.

## Third-Party Services

The app may be distributed through Google Play. Google Play may process download, purchase, crash, device, or account information according to Google's own policies. Those Google Play practices are controlled by Google, not by VOID UI Icon Pack.

## Children's Privacy

VOID UI Icon Pack is not directed at children and does not knowingly collect data from children.

## Changes

This policy may be updated if the app's behavior changes. Any material change will be reflected by updating this document.
